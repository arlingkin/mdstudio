Privacy Policy

mdstudio · Effective 2026-11-10

mdstudio is a personal, static Markdown editor and previewer. It can open files from your device, Google Drive, and public GitHub repositories. This page explains what data the app touches and what it does with it.

Google user data

  • Scope requested: https://www.googleapis.com/auth/drive, used only to list, open, create, and update files and folders you choose in your own Google Drive.
  • File contents are fetched directly between your browser and Google APIs. They are not sent to or stored on our server.
  • The Google login runs through serverless functions that exchange the OAuth code for tokens. The refresh token is encrypted (AES-256-GCM) and stored only in an httpOnly cookie in your browser. Short-lived access tokens are kept in browser memory only.
  • Deleting a file from the app moves it to your Google Drive trash; it is not permanently deleted.
  • We do not use Google user data for advertising, analytics, profiling, or sale, and we do not share it with third parties.
  • mdstudio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data stored in your browser

  • IndexedDB: your open workspace (file paths, contents, edit state) for autosave and offline recovery.
  • localStorage: preferences such as language, theme, view mode, and autosave toggle.
  • sessionStorage: an optional GitHub personal access token, only if you enter one, cleared when the tab closes.
  • Cookie ms_rt: the encrypted Google refresh token described above.

GitHub

Repositories are read from api.github.com and raw.githubusercontent.com directly by your browser. If you commit, requests go to GitHub with the token you provided. The token is not sent to our server.

Images and external links

Markdown can embed images by https URL, including CDNs, badges, charts and GIFs. When such a document is previewed, your browser requests the image directly from that host, which can see your IP address and user agent. mdstudio sends no referrer with these requests. Relative image paths are resolved locally from your workspace and are never sent anywhere. The preview site sandbox may also load https images.

Server and hosting

The app is hosted on Vercel, which may keep standard request logs (such as IP address and user agent). We run no database, no analytics, and no advertising.

Your control

  • Use logout in the app to revoke the Google token and delete the cookie.
  • Revoke access any time at myaccount.google.com/permissions.
  • Clear site data in your browser to remove IndexedDB, localStorage, and sessionStorage.

Contact and changes

Questions or requests: open an issue at github.com/arlingkin/mdstudio/issues. This policy may change; the effective date above will be updated.

Kebijakan Privasi

mdstudio · Berlaku 2026-11-10

mdstudio adalah editor dan pratinjau Markdown statis untuk penggunaan pribadi. Aplikasi bisa membuka file dari perangkatmu, Google Drive, dan repositori GitHub publik. Halaman ini menjelaskan data apa yang disentuh aplikasi dan bagaimana dipakai.

Data pengguna Google

  • Scope yang diminta: https://www.googleapis.com/auth/drive, dipakai hanya untuk menampilkan, membuka, membuat, dan memperbarui file serta folder yang kamu pilih di Google Drive milikmu.
  • Isi file diambil langsung antara browsermu dan Google API. Isi file tidak dikirim ke atau disimpan di server kami.
  • Login Google berjalan lewat serverless function yang menukar kode OAuth dengan token. Refresh token dienkripsi (AES-256-GCM) dan disimpan hanya di cookie httpOnly di browsermu. Access token berumur pendek hanya disimpan di memori browser.
  • Menghapus berkas dari aplikasi memindahkannya ke sampah Google Drive; berkas tidak dihapus permanen.
  • Kami tidak memakai data pengguna Google untuk iklan, analitik, profiling, atau dijual, dan tidak membagikannya ke pihak ketiga.
  • Penggunaan informasi dari Google API oleh mdstudio mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use.

Data yang disimpan di browsermu

  • IndexedDB: workspace yang sedang dibuka (path file, isi, status edit) untuk autosave dan pemulihan offline.
  • localStorage: preferensi seperti bahasa, tema, mode tampilan, dan toggle autosave.
  • sessionStorage: GitHub personal access token opsional, hanya jika kamu memasukkannya, hilang saat tab ditutup.
  • Cookie ms_rt: refresh token Google terenkripsi seperti dijelaskan di atas.

GitHub

Repositori dibaca dari api.github.com dan raw.githubusercontent.com langsung oleh browsermu. Jika kamu commit, request dikirim ke GitHub dengan token yang kamu berikan. Token tidak dikirim ke server kami.

Gambar dan tautan eksternal

Markdown bisa menyematkan gambar lewat URL https, termasuk CDN, badge, grafik, dan GIF. Saat dokumen seperti itu dipratinjau, browsermu meminta gambar langsung ke host tersebut, yang bisa melihat alamat IP dan user agent-mu. mdstudio tidak mengirim referrer pada permintaan ini. Path gambar relatif diselesaikan secara lokal dari workspace-mu dan tidak pernah dikirim ke mana pun. Sandbox pratinjau situs juga bisa memuat gambar https.

Server dan hosting

Aplikasi di-host di Vercel, yang bisa menyimpan log request standar (misalnya alamat IP dan user agent). Kami tidak menjalankan database, analitik, maupun iklan.

Kendalimu

  • Pakai logout di aplikasi untuk mencabut token Google dan menghapus cookie.
  • Cabut akses kapan saja di myaccount.google.com/permissions.
  • Hapus data situs di browser untuk membersihkan IndexedDB, localStorage, dan sessionStorage.

Kontak dan perubahan

Pertanyaan atau permintaan: buka issue di github.com/arlingkin/mdstudio/issues. Kebijakan ini bisa berubah; tanggal berlaku di atas akan diperbarui.
