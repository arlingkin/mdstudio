Quick startMulai cepat

  1. Pick a source. On the home screen choose new, open, folder, Google Drive or GitHub.
  2. Write & preview. Type Markdown on one side and read the rendered page on the other.
  3. Save & sync. Drafts autosave in your browser. Send a file to Drive with to drive, or commit & push GitHub files.

Press Ctrl/⌘K anywhere to open the command palette: every action is searchable.

  1. Pilih sumber. Di layar awal pilih baru, buka, folder, Google Drive, atau GitHub.
  2. Tulis & lihat hasil. Ketik Markdown di satu sisi, hasil render tampil di sisi lain.
  3. Simpan & sinkron. Draf tersimpan otomatis di browser. Kirim ke Drive dengan ke drive, atau commit & push untuk berkas GitHub.

Tekan Ctrl/⌘K kapan saja untuk membuka palet perintah: semua aksi bisa dicari.

DesktopDesktop

The desktop layout is built for keyboard and mouse.

  • Header: sidebar toggle, mode switch (editor / split / preview), commands, theme and language.
  • Toolbar: actions grouped by scope with a mini logo and a thin divider: browser & device, Google Drive, GitHub and view. Below 1200 px wide the buttons show icons only; hover for the name. Buttons that do not apply to the current file are dimmed.
  • Sidebar: file tree, Google Drive (after sign-in) and the GitHub box. The footer links to this guide, Privacy and Terms.
  • Workspace: tabs, a formatting toolbar, and the editor next to the preview. Drag the divider to resize (double-click resets, arrow keys nudge).
  • Status bar: current file and source, word count, reading time, line and column.

Power features

  • Command palette Ctrl/⌘K: type to filter, ↑ ↓ to move, Enter to run.
  • Focus mode Ctrl/⌘ShiftF hides all chrome; Esc exits.
  • Smart lists: Enter continues bullets, numbers and tasks; on an empty item it ends the list.
  • Synced scroll: in split mode the preview follows the editor.
  • Folders: folder uses the File System Access API (Chrome, Edge and other Chromium browsers). Elsewhere use open.

Tata letak desktop dibuat untuk keyboard dan mouse.

  • Header: tombol panel samping, pengalih mode (editor / split / pratinjau), perintah, tema, dan bahasa.
  • Toolbar: aksi dikelompokkan per lingkup dengan logo mini dan garis pemisah tipis: browser & perangkat, Google Drive, GitHub, dan tampilan. Di bawah lebar 1200 px tombol hanya berikon; arahkan kursor untuk melihat namanya. Tombol yang tidak berlaku untuk berkas saat ini diredupkan.
  • Panel samping: pohon berkas, Google Drive (setelah login), dan kotak GitHub. Footer berisi tautan ke panduan ini, Privasi, dan Ketentuan.
  • Area kerja: tab, toolbar format, serta editor di samping pratinjau. Seret pembatas untuk mengubah ukuran (klik ganda untuk reset, tombol panah untuk geser halus).
  • Bilah status: berkas dan sumbernya, jumlah kata, waktu baca, baris dan kolom.

Fitur lanjutan

  • Palet perintah Ctrl/⌘K: ketik untuk menyaring, ↑ ↓ untuk pindah, Enter untuk menjalankan.
  • Mode fokus Ctrl/⌘ShiftF menyembunyikan semua antarmuka; Esc untuk keluar.
  • Daftar pintar: Enter melanjutkan bullet, nomor, dan tugas; pada item kosong, daftar berakhir.
  • Scroll sinkron: di mode split pratinjau mengikuti editor.
  • Folder: folder memakai File System Access API (Chrome, Edge, dan browser Chromium lain). Di browser lain pakai buka.

MobileMobile

On screens up to 800 px wide the layout switches to a one-hand design.

  • Bottom bar: files, editor, preview and more. The highlighted tab shows where you are.
  • Files: tap files to slide in the file panel. Tap outside it, or press back/Esc, to close.
  • More: opens a sheet with the same actions grouped by scope (device, Drive, GitHub, view). It closes after you pick an action.
  • Formatting strip: sits above the bottom bar while you edit. Swipe sideways for more buttons.
  • One pane at a time: there is no split mode on small screens; switch with the bottom bar.
  • Top bar: commands, theme and language.

Most mobile browsers cannot pick folders. Use open to choose files from the system picker, or load a repository from GitHub.

Pada layar selebar 800 px atau kurang, tata letak berganti ke desain satu tangan.

  • Bilah bawah: berkas, editor, pratinjau, dan lainnya. Tab yang menyala menunjukkan posisi Anda.
  • Berkas: ketuk berkas untuk membuka panel berkas. Ketuk di luar panel atau tekan tombol kembali/Esc untuk menutup.
  • Lainnya: membuka lembar berisi aksi yang sama, dikelompokkan per lingkup (perangkat, Drive, GitHub, tampilan). Lembar menutup setelah Anda memilih aksi.
  • Strip format: berada di atas bilah bawah saat mengedit. Geser ke samping untuk tombol lain.
  • Satu panel sekali: tidak ada mode split di layar kecil; ganti lewat bilah bawah.
  • Bilah atas: perintah, tema, dan bahasa.

Kebanyakan browser mobile tidak bisa memilih folder. Pakai buka untuk memilih berkas dari pemilih sistem, atau muat repositori dari GitHub.

Web & browserWeb & browser

  • mdstudio runs in any modern browser with no install and no account.
  • Where data lives: drafts are stored in this browser (IndexedDB). Clearing site data or using a private window removes them, so keep important files on Drive or GitHub.
  • Preferences: theme, language, view mode, sidebar and divider position are remembered per browser.
  • Sharing a repo: use ?repo=user/repo&ref=branch&path=file in the address.
  • Safety: rendered HTML is sanitized; the run preview executes inside a sandboxed frame.
  • mdstudio berjalan di browser modern tanpa instalasi dan tanpa akun.
  • Lokasi data: draf disimpan di browser ini (IndexedDB). Menghapus data situs atau memakai jendela privat akan menghapusnya, jadi simpan berkas penting di Drive atau GitHub.
  • Preferensi: tema, bahasa, mode tampilan, panel samping, dan posisi pembatas diingat per browser.
  • Membagikan repo: pakai ?repo=user/repo&ref=branch&path=file di alamat.
  • Keamanan: HTML hasil render disanitasi; pratinjau jalankan berjalan di frame ber-sandbox.

Google DriveGoogle Drive

  1. Press drive and sign in with Google.
  2. Pick a file in the drive section of the sidebar and edit it.
  3. Watch the status: saved, saving…, unsaved, conflict or login needed.
  4. To store a local or GitHub file in Drive, press to drive.
  5. Autosave uploads Drive files as you type. It never touches device or GitHub files.
  6. Use logout in the Drive header to sign out.

If a file changed on Drive since you opened it, mdstudio asks before overwriting.

  1. Tekan drive dan masuk dengan Google.
  2. Pilih berkas di bagian drive pada panel samping lalu edit.
  3. Perhatikan status: tersimpan, menyimpan…, belum tersimpan, konflik, atau perlu login.
  4. Untuk menyimpan berkas lokal atau GitHub ke Drive, tekan ke drive.
  5. Autosave mengunggah berkas Drive saat Anda mengetik. Tidak pernah menyentuh berkas perangkat atau GitHub.
  6. Pakai keluar di header Drive untuk logout.

Jika berkas berubah di Drive sejak Anda membukanya, mdstudio bertanya sebelum menimpa.

GitHubGitHub

  1. Paste user/repo or a /tree/… or /blob/… link in the GitHub box and press load.
  2. Open files from the tree; they load on demand. Binary and files over 1 MB are skipped.
  3. run previews the nearest index.html in a sandbox.
  4. For private repos or pushing, add a fine-grained token with contents write access under token. It stays in this tab only.
  5. commit & push makes one commit without force. If the remote changed, nothing is overwritten.
  6. copy to drive copies the file or folder to Google Drive.
  1. Tempel user/repo atau link /tree/… atau /blob/… di kotak GitHub lalu tekan muat.
  2. Buka berkas dari pohon; dimuat saat dibutuhkan. Berkas biner dan di atas 1 MB dilewati.
  3. jalankan menampilkan index.html terdekat dalam sandbox.
  4. Untuk repo privat atau push, isi token fine-grained dengan akses tulis contents di token. Token hanya hidup di tab ini.
  5. commit & push membuat satu commit tanpa force. Jika remote berubah, tidak ada yang ditimpa.
  6. salin ke drive menyalin berkas atau folder ke Google Drive.

Markdown & front matterMarkdown & front matter

Tables, task lists, fenced code with highlighting and sanitized HTML are supported. Optional front matter at the top of a file:

---
layout: wide
theme: light
toc: true
---
layoutnarrow | wide
themedark | light
toctrue | false

The toolbar inserts bold, italic, strikethrough, code, headings, quotes, lists, tasks, links, tables, code blocks and dividers.

Tabel, daftar tugas, kode berpagar dengan penyorotan, dan HTML tersanitasi didukung. Front matter opsional di bagian atas berkas:

---
layout: wide
theme: light
toc: true
---
layoutnarrow | wide
themedark | light

Toolbar menyisipkan tebal, miring, coret, kode, judul, kutipan, daftar, tugas, tautan, tabel, blok kode, dan pemisah.

TroubleshootingPemecahan masalah

  • “Backend not reachable”: Drive sign-in needs the Vercel deployment; it does not work on a plain static server.
  • Files disappeared: browser data was cleared, or you were in a private window.
  • Push says remote changed: reload the repository, merge manually, then push again.
  • Not found or private: add a token in the GitHub box.
  • Rate limit reached: add a token; the remaining quota is shown under the GitHub box.
  • Folder button missing: your browser does not support folder access; use open.
  • Icons not showing locally: serve the folder over HTTP (python -m http.server); opening index.html directly blocks the icon file.
  • “Backend tidak terjangkau”: login Drive membutuhkan deployment Vercel; tidak berfungsi di server statis biasa.
  • Berkas hilang: data browser terhapus, atau Anda memakai jendela privat.
  • Push menyatakan remote berubah: muat ulang repositori, gabungkan manual, lalu push lagi.
  • Tidak ditemukan atau privat: isi token di kotak GitHub.
  • Batas API tercapai: isi token; sisa kuota tampil di bawah kotak GitHub.
  • Tombol folder tidak ada: browser Anda tidak mendukung akses folder; pakai buka.
  • Ikon tidak muncul secara lokal: sajikan folder lewat HTTP (python -m http.server); membuka index.html langsung memblokir berkas ikon.
